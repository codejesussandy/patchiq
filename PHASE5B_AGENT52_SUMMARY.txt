================================================================================
KEY INSIGHT: WHY TEST EDGE?
================================================================================

Edge is Chromium-based - same engine as Chrome.

IDENTICAL (Same Chromium Components):
  • JavaScript engine (V8)
  • CSS rendering (Blink)
  • HTML parsing
  • Network stack
  • WebAPI support
  • Storage (localStorage, IndexedDB, etc.)
  • Service Workers, Web Workers
  • WebSockets, Fetch API

DIFFERENT (Browser UI Only - Don't Matter for App):
  • Address bar styling
  • Button styling
  • Default search engine (Bing vs Google)
  • Extensions (Edge Add-ons vs Chrome Web Store)
  • Telemetry (Microsoft vs Google)
  • Sync backend (Microsoft vs Google)

EXPECTED RESULT:
  Edge should behave 99%+ identically to Chrome
