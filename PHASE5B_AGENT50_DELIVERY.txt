KNOWN FIREFOX ISSUES DOCUMENTED
================================================================================

7 FIREFOX-SPECIFIC ISSUES WITH MITIGATIONS:

1. EventSource (SSE) Long Connection Timeout (Medium)
   - May disconnect after 5-45 minutes
   - Fix: Server-side keep-alive heartbeat
   - Test: Monitor 15+ minutes for stability

2. Custom Scrollbar Styling (Low - Acceptable)
   - Firefox shows native scrollbars
   - Acceptable difference (not a bug)
   - Mitigation: Use CSS scrollbar-width

3. CSS Variables in Dark Mode (Low - Acceptable)
   - Minor timing differences on theme toggle
   - Acceptable performance variance
   - Mitigation: Batch CSS updates

4. SVG Rendering in Charts (Low - Acceptable)
   - Minor visual differences in edge cases
   - Functional (no blocking issues)
   - Mitigation: Test SVG filters and effects

5. Date Input Styling (Low - Acceptable)
   - Limited CSS customization
   - Both browsers functional
   - Acceptable difference

6. Form Validation & Input Focus (Low - Acceptable)
   - Minor differences in validation display
   - All validation messages functional
   - Acceptable visual difference

7. Performance Differences (Low - Acceptable)
   - Firefox may be 10-20% slower
   - Acceptable if >80% parity
   - Platform-dependent difference

NONE BLOCKING: All issues have mitigations or are acceptable differences
