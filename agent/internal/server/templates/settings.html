CLI Commands Reference

Interactive setup wizard:
./patchify-agent --setup
Check connection status:
./patchify-agent --status
Run in local-only mode (no server):
./patchify-agent --no-backend
Specify custom config file:
./patchify-agent --config /path/to/config.json
Change Web UI port:
./patchify-agent --port 9090

API Endpoints
