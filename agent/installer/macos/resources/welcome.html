Welcome to PatchIQ Agent Installer

This installer will guide you through the installation of PatchIQ Agent on your Mac.

What is PatchIQ Agent?

PatchIQ Agent provides automated patch management, software deployment, and system inventory collection for your Mac. It connects to your PatchIQ Hub for centralized management.

What will be installed:

  • PatchIQ Agent binary at /usr/local/bin/patchiq-agent
  • LaunchDaemon for system-wide automatic startup
  • Log directory at /var/log/patchiq

System Requirements:

  • macOS 10.13 (High Sierra) or later
  • 50 MB available disk space
  • Network connectivity to PatchIQ Hub
