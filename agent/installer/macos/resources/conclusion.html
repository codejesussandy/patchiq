Useful Commands:

Check agent status:

launchctl list | grep patchiq

View logs:

tail -f /var/log/patchiq/agent.log

Stop the agent:

launchctl stop io.patchiq.agent

Start the agent:

launchctl start io.patchiq.agent

Uninstall:

To remove PatchIQ Agent, run:

sudo /usr/local/bin/patchiq-agent-uninstall.sh
