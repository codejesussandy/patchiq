## Testing Methodology

### The Test Suite

The Edge baseline test (`phase5b-agent52-edge-baseline.spec.ts`) executes:

1. **Authentication** - Login/logout flow verification
2. **Dashboard** - Stats cards, charts, navigation
3. **Assets Module** - List view, search, filter, detail pages, tabs
4. **Patches Module** - List view, search, filter, detail pages
5. **Vulnerabilities** - List view with CVSS scores, detail pages
6. **Settings Module** - User management, organization settings, navigation
7. **Hub Module** - Package display and search
8. **Discovery Module** - IP discovery page load and interactivity

### Data Capture

For each test, the suite captures:

```javascript
- Module name
- Functionality tested
- Console error count
- Console warning count
- Visual issues (if any)
- Pass/fail status
- Detailed notes
- Full-page screenshots
```

### Report Generation

The test automatically generates:

1. **Browser Information**
   - Edge version (e.g., 125.0.6422.142)
   - Chromium version (e.g., 125.0.6422.142)
   - Operating system
   - User agent string

2. **Results Table**
   ```markdown
   | Module | Functionality | Errors | Issues | Status |
   |--------|---------------|--------|--------|--------|
   | Auth | Login flow | 0 | None | PASS |
   | Dashboard | Stats, charts | 0 | None | PASS |
   ...
   ```

3. **Chrome Comparison**
   - Expected behaviors (identical to Chrome)
   - Known differences (none expected)
   - Actual differences (should be 0)

4. **Recommendations**
   - Whether Edge-specific testing is needed
   - Which browsers to prioritize
   - Future testing strategy

## Key Insights

### Why Edge Equals Chrome

Edge uses Chromium, the same open-source browser engine as Chrome:

| Component | Chrome | Edge | Impact |
|-----------|--------|------|--------|
| JavaScript Engine | V8 | V8 | IDENTICAL |
| CSS Engine | Blink | Blink | IDENTICAL |
| HTML Parser | Blink | Blink | IDENTICAL |
| Network Stack | Custom | Same | IDENTICAL |
| WebAPI Support | Chromium | Chromium | IDENTICAL |

### What's Different (Browser UI Only)

| Feature | Chrome | Edge | App Impact |
|---------|--------|------|-----------|
| Address bar | Chrome style | Edge style | NONE |
| Buttons | Chrome style | Edge style | NONE |
| Default search | Google | Bing | NONE |
| Extensions | Chrome Web Store | Edge Add-ons | NONE |
| Telemetry | Google | Microsoft | NONE |

**Bottom Line**: The app doesn't see these differences. They're browser UI only.

## Troubleshooting Guide

### "Edge not found" Error

**Cause**: Edge browser not installed

**Fix**:
```bash
# macOS
brew install microsoft-edge

# Windows
# Download from microsoft.com/edge

# Linux
# Follow distro package manager
```

### "Failed to install msedge" Error

**Cause**: Playwright browsers not installed

**Fix**:
```bash
npx playwright install msedge
# If that fails and you have sudo:
npx playwright install msedge --with-deps
```

### Test Timeout

**Cause**: Services not running

**Fix**:
```bash
# In separate terminals:
make dev-backend
make dev-frontend

# Verify connectivity:
curl http://localhost:5173
```

### Authentication Fails

**Cause**: auth.json missing or invalid

**Fix**:
```bash
# Run setup first
npm test -- e2e/auth.setup.ts

# Then run Edge test
npm test -- phase5b-agent52-edge-baseline.spec.ts
```

### Different Results than Chrome

**Cause**: Browser data, cache, extensions

**Fix**:
```bash
# Use Edge InPrivate (equivalent to Chrome Incognito)
# Or clear browser data:
# Edge: Settings > Privacy > Clear browsing data
```
