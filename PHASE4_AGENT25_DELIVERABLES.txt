INTEGRATION REQUIREMENTS
================================================================================

Backend API Endpoints Required:
  POST   /api/zero-touch-configs              (Create)
  GET    /api/zero-touch-configs              (List all)
  GET    /api/zero-touch-configs/:id          (Get single)
  PUT    /api/zero-touch-configs/:id          (Update)
  DELETE /api/zero-touch-configs/:id          (Delete)

Database Schema Required:
  - zero_touch_configs table
  - Fields: id, name, description, applicationType, scope,
            autoDeploymentRules (JSONB), status, createdBy,
            createdOn, updatedOn, organizationId
  - Indexes: name, organizationId, status
  - Constraints: UNIQUE(name, organizationId)

API Response Format:
  {
    "success": true,
    "data": { ZeroTouchConfig object },
    "meta": { pagination info }
  }

Error Response Format:
  {
    "success": false,
    "error": {
      "code": "ERROR_CODE",
      "message": "Human-readable message"
    }
  }
