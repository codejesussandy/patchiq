KNOWN FIREFOX ISSUES TO WATCH FOR

   Status: Known Firefox behavior
   Impact: Real-time notifications may stop after 5-45 minutes
   Detection: Monitor Network tab for EventSource connection
   Mitigation: Implement server-side keep-alive (30-second heartbeat)
   Test Duration: 15+ minutes minimum

2. CUSTOM SCROLLBAR STYLING
   Status: Firefox limitation (not a bug)
   Impact: Shows native scrollbars instead of custom styled
   Detection: Compare scrollbar appearance vs Chrome screenshot
   Status: ACCEPTABLE DIFFERENCE (not a blocking issue)

3. DATE INPUT STYLING
   Status: Firefox limitation (not a bug)
   Impact: Date picker styling more limited than Chrome
   Detection: Test date inputs in forms
   Status: ACCEPTABLE DIFFERENCE (both functional)

4. PERFORMANCE DIFFERENCES
   Status: May vary by hardware
   Impact: Firefox might be 10-20% slower on older hardware
   Detection: Use DevTools Performance tab to measure
   Status: ACCEPTABLE if >80% parity with Chrome

================================================================================
QUICK REFERENCE: WHAT TO LOOK FOR
================================================================================

RENDERING ISSUES:
  • SVG charts rendering with artifacts
  • Text truncation or overflow
  • Layout shifts during data load
  • Modal/dropdown positioning problems
  • Color display differences

FUNCTIONAL ISSUES:
  • Form validation not appearing
  • Buttons not responding
  • Search/filter not working
  • Real-time updates not appearing
  • Links not opening

PERFORMANCE ISSUES:
  • Page load time >3 seconds
  • Scrolling less than 30 FPS
  • Memory usage growing continuously
  • CPU usage spike on interaction
  • Animation stuttering

CONSOLE ISSUES:
  • TypeError: Cannot read property X
  • ReferenceError: Y is not defined
  • Uncaught Promise rejection
  • CORS errors
  • 404 API errors
