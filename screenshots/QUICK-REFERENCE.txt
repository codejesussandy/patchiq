3️⃣  PATCHES
   • Summary cards (Total, Installed, Pending, Failed)
   • Patch list with KB numbers
   • Installation status
   • Supersedence chains
   • Deploy actions
   • Recommendations

4️⃣  ALERTS
   • Alert type and severity
   • Messages with timestamps
   • Status (Active/Resolved/Acknowledged)
   • Acknowledge/Resolve actions
   • Real-time updates

5️⃣  AUDIT LOG
   • User actions with timestamps
   • Changed fields (before/after)
   • IP addresses
   • Source tracking
   • Paginated history (20 per page)
   • Immutable trail for compliance

6️⃣  SOFTWARE
   • Installed software list
   • Versions and publishers
   • Install dates
   • License status
   • Vulnerability counts (clickable)
   • Uninstall actions
