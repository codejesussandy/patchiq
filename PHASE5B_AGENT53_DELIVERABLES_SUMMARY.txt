================================================================================
TECHNICAL CHALLENGES IDENTIFIED
================================================================================

1. MULTI-STEP MODAL FORM
   Challenge:  AddAssetModal uses Ant Design Steps with 3 sequential forms
   Impact:     Cannot automate form filling without stable selectors
   Solution:   Manual testing or add data-testid attributes

2. DYNAMIC SELECTORS
   Challenge:  Generic CSS classes (.ant-select, .ant-input)
   Impact:     Multiple matching elements, ambiguous targeting
   Solution:   Use proximity selectors or label-based matching

3. CONTEXT-DEPENDENT FIELDS
   Challenge:  Field visibility depends on previous selections
   Impact:     Cannot pre-determine form structure
   Solution:   Conditional logic or manual intervention

4. ASYNC STATE MANAGEMENT
   Challenge:  Form validation with debouncing, character counters
   Impact:     Timing-sensitive interactions
   Solution:   Explicit waits or manual pacing
